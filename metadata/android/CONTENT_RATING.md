# Google Play — Content Rating (IARC) Questionnaire Answers (WortKrieg)

Play Console → App content → Content ratings. Category: **Reference, News, or Educational**.
WortKrieg is an educational vocabulary app with no objectionable content. Answer the IARC
questionnaire as follows (all "No" unless noted):

| Question | Answer |
|---|---|
| Violence (cartoon/fantasy/realistic) | No |
| Blood / gore | No |
| Sexual content or nudity | No |
| Profanity or crude humor | No |
| Use/reference to drugs, alcohol, tobacco | No |
| Gambling (simulated or real) | No |
| Scary / horror content | No |
| User-generated content / user interaction | **Yes** — users can interact (1v1 battles, friends, study groups, leaderboards) |
| Does the app share the user's location with other users? | No |
| Does the app allow users to communicate / share content? | **Yes, limited** — competitive battles, friend challenges, study groups. No open free-text chat is shipped by default; if you enable any chat, declare it. |
| Digital purchases (in-app purchases) | **Yes** — freemium / premium subscription (if IAP is enabled at launch) |
| In-app advertising | No |

### Notes
- The word "Krieg" (war) / "WortKampf" (word battle) and the "battle" theme are **metaphorical
  competition** (quiz duels), not violence. Answer violence questions **No**.
- "Battle / war" wording is branding for a vocabulary quiz duel — clarify in the review notes
  to avoid a mistaken violence flag.
- Expected resulting rating: **Everyone / PEGI 3 / USK 0 / 3+** (general audience).

### Target audience & content
- Target age group: 13+ recommended (social/competitive features), suitable for general audience.
- Not designed for or directed at children under 13. Do not opt into "Designed for Families".
